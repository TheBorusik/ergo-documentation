# Наборы позиций (шаблоны установок)

Решение 2026-07-24 (запрос пользователя). Готовые группы позиций каталога
для быстрого добавления в спецификацию проекта — вместо поштучного выбора.

## Суть
Проектировщик собирает набор один раз (напр. «Приточная секция»: клапан +
воздуховод + отвод + шумоглушитель + решётка одного типоразмера) и потом
добавляет его в спецификацию целиком. У каждой позиции набора — БАЗОВОЕ
кол-во, которое можно поправить после добавления.

Наборы ОБЩИЕ (один каталог на всех) — это просто группировка позиций для
удобства. Проверки совместимости позиций пока НЕТ (продумаем позже).

## Модель
```
position_sets       id · name · description
position_set_items  id · set_id → position_sets
                    element_position_id → element_positions (позиция каталога)
                    quantity (базовое кол-во)
```

## API (мок; снятие = удаление из handlers.ts)
- `PositionSets.Query` → список наборов (Id, Name, Description, ItemsCount).
- `PositionSets.Get {SetId}` → набор с позициями (Name/Article/Quantity).
- `PositionSets.Save {Id, Name, Description, Items[]}` — upsert (Id=0 новый,
  иначе пересоздание строк).
- `PositionSets.Delete {Id}`.

## UI
- Номенклатура → Каталог: переключатель **[Каталог | Наборы]**. Вкладка
  «Наборы» — список наборов (создать/изменить/удалить). Конструктор набора —
  фасетный выбор позиций (тот же FacetFilter scope=catalog) + корзина с
  кол-вом + имя/описание.
- Окно выбора позиций проектировщика (`ChangeCompositionModal`) —
  переключатель **[Каталог | Наборы]** в тулбаре. Вкладка «Наборы»: выбрал
  набор → «В спецификацию» → все его позиции падают в корзину с базовым
  кол-вом (дальше правятся как обычные строки черновика).
